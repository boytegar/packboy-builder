# PDF Document Generation

## When to use
- User requests a PDF report, invoice, resume, or letter
- Need polished, printable document output
- Generating certificates or flyers

## Approach
1. Structure the content (sections, headings, body)
2. Apply typography rules (margins, font sizes, line height)
3. Add visual elements (tables, charts, images)
4. Export to PDF

## Typography rules
- Body: 10-11pt, line height 1.4-1.5
- Headings: 14-24pt, bold
- Margins: 1 inch (2.54cm) or 0.75 inch for dense documents
- Page numbers in footer
- Title page for formal documents

## Document types
- **Report**: title page, TOC, sections, conclusion, appendix
- **Invoice**: company info, client info, line items, totals, payment terms
- **Resume**: contact, summary, experience, education, skills
- **Letter**: sender, date, recipient, body, signature
- **Certificate**: title, recipient name, achievement, date, signature

## Output quality
- Consistent spacing throughout
- No orphan/widow lines (single lines at top/bottom of page)
- Aligned tables with consistent borders
- Readable font sizes (never below 8pt)
- Print-safe colors (test in grayscale)
