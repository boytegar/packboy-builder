# Brand Design

## When to use
- Creating a brand identity (logo, colors, typography)
- Designing visual guidelines
- Generating brand kit boards and presentations

## Brand identity components
- **Logo system**: primary, secondary, monogram, favicon variants
- **Color palette**: primary, secondary, accent, neutral ramp
- **Typography**: heading, body, mono — with weights and sizes
- **Spacing system**: consistent margins, padding, gaps
- **Iconography**: style guide for icons (outline, filled, duotone)
- **Photography**: art direction, mood, composition rules

## Color palette design
- Primary: the main brand color (1 color)
- Secondary: supports primary (1-2 colors)
- Accent: high-contrast CTA color (1 color)
- Neutrals: gray ramp from black to white (5-7 shades)
- Semantic: success (green), error (red), warning (yellow), info (blue)
- Dark + light mode variants

## Typography rules
- 1-2 typefaces maximum (heading + body, or one with weights)
- Type scale: 1.25 or 1.333 ratio between sizes
- Line height: 1.5 for body, 1.1-1.2 for headings
- Don't set line lengths > 80 chars
- Use system fonts for performance when possible

## Logo design principles
- Simple: recognizable at small sizes
- Scalable: works at 16px and 1000px
- Memorable: unique, not generic
- Versatile: works in color and monochrome
- Timeless: avoid trendy effects
- Appropriate: fits the brand personality

## Anti-patterns
- Too many colors (no hierarchy)
- Trendy gradients that date quickly
- Illegible at small sizes
- Different logo variants that don't feel related
- No dark mode consideration
