# Word Document Generation

## When to use
- User requests a Word document, .docx file, or printable document
- Need formatted text document with structure
- Generating reports, letters, or proposals

## Document structure
- **Title**: document title, centered, large font
- **Headings**: H1 for sections, H2 for subsections, numbered
- **Body paragraphs**: justified or left-aligned, 1.5 line spacing
- **Lists**: bullet or numbered, consistent indentation
- **Tables**: bordered, header row bold
- **Footer**: page numbers, document title
- **Header**: optional, for multi-page documents

## Formatting standards
- Font: Times New Roman 12pt or Arial 11pt (or modern: Calibri, Inter)
- Margins: 1 inch (2.54cm) standard
- Line spacing: 1.15-1.5 for readability
- Paragraph spacing: 6-12pt after, not before
- Headings: 14-16pt bold, more spacing before than after

## Document types
- **Report**: title, TOC, sections, conclusion, references
- **Letter**: sender block, date, recipient, salutation, body, closing, signature
- **Proposal**: executive summary, problem, solution, timeline, budget
- **Memo**: header (To/From/Date/Subject), body, action items
