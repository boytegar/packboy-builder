# PowerPoint Generation

## When to use
- User requests a presentation, deck, or slides
- Need polished, export-to-PowerPoint output
- Creating pitch decks or slide shows

## Slide structure
1. **Title slide**: title, subtitle, presenter, date
2. **Agenda**: outline of presentation
3. **Content slides**: one idea per slide, heading + body
4. **Visual slides**: charts, diagrams, images
5. **Conclusion**: summary, call to action
6. **Q&A slide**: contact info

## Design rules
- One idea per slide (don't cram)
- 6x6 rule: max 6 bullets, 6 words each (guideline, not law)
- High contrast text on background
- Consistent font (1-2 typefaces)
- Consistent color scheme (from brand palette)
- Images: full-bleed or consistently framed
- No walls of text — use visuals

## Common slide types
- **Title**: big text, minimal elements
- **Bullet**: heading + 3-5 short bullets
- **Image**: full image + caption
- **Chart**: data visualization with title and takeaway
- **Quote**: large quote, attribution
- **Section divider**: visual break between sections
- **Comparison**: two-column or before/after
